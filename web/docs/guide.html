Warum „Load failed“?

Der Browser erhält keine nutzbare Antwort vom Cloudflare Worker. Öffne /health und prüfe, ob der Worker aktiv ist, groq_configured und chat_rate_limit_configured auf true stehen und origin_allowed für deine Webseite true ist.

Ohne korrekt deployten Worker gibt es keinen Groq-Chat und keine Live-JPL-Abfrage.

Cloudflare + Groq einrichten

  1. API-Key auf Groq Keys erstellen.
  2. In cloudflare/wrangler.jsonc die echte Website-Adresse unter ALLOWED_ORIGINS ergänzen.
  3. Im Terminal: cd cloudflare, npm install, npx wrangler login, npx wrangler deploy.
  4. npx wrangler secret put GROQ_API_KEY ausführen und den Schlüssel ausschließlich dort eingeben.
  5. Auf der Webseite „VERBINDUNG PRÜFEN“ klicken.

Echte NASA-Daten

„JPL LIVE LADEN“ fragt geometrische Sonnen-/Erdazimute und -höhen direkt bei NASA/JPL über den Worker ab. Die LRO-Mondtextur ist echtes NASA-Bildmaterial, sobald sie geladen wurde. Eis-, Hang-, Temperaturwerte, PSR-Polygone und der lokale ML-Score bleiben Demo-Daten und sind nicht durch NASA validiert.

Why “Load failed”?

Your browser cannot obtain a usable response from the Cloudflare Worker. Open /health and check that the Worker is deployed; that groq_configured and chat_rate_limit_configured are true; and that origin_allowed is true for your actual website.

Without a configured deployment, neither Groq chat nor live JPL data will work.

Set up Cloudflare + Groq

  1. Create a key via Groq Keys.
  2. Edit ALLOWED_ORIGINS in cloudflare/wrangler.jsonc to include your site's exact origin.
  3. Run cd cloudflare, npm install, npx wrangler login, npx wrangler deploy.
  4. Run npx wrangler secret put GROQ_API_KEY and enter the private key there only.
  5. Click “VERBINDUNG PRÜFEN” in the dashboard.

Genuine NASA data

“JPL LIVE LADEN” requests geometrical Sun/Earth elevation and azimuth via NASA/JPL through the Worker. The LRO Moon texture uses real NASA imagery once loaded. Ice/slope/temperature values, PSR polygons and the local ML score remain demo values and are not NASA-verified.
